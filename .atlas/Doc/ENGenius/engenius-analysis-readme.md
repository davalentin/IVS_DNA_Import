# README artefatti IVS Modernizzazione

- `01_business_requirements.md` — Catalogo dei BR-001..BR-007 e dei ruoli di riferimento del progetto.
- `02_functional_requirements.md` — Aree funzionali FA-001..FA-007 e catalogo dei requisiti funzionali derivati dal PRD.
- `03_features.md` — Feature catalog tracciato verso business requirement e functional requirement.
- `04_use_cases.md` — Catalogo dei casi d’uso operativi e amministrativi del sistema modernizzato.
- `04b_scenarios.md` — Scenari principali, alternativi ed eccezionali con passi operativi dettagliati.
- `04c_non_functional_requirements.md` — Aree di qualità e NFR-001..NFR-026 derivati dal PRD.

## Nota di tracciabilità
La catena di tracciabilità applicata è: BR -> FA/FR -> Feature -> Use Case -> Scenario; i requisiti non funzionali operano come vincoli trasversali di qualità e conformità.
